# Ảnh mẫu thật (tuỳ chọn)

Mặc định app dùng hình minh hoạ vẽ sẵn. Muốn dùng **ảnh thật** của quán bạn, bỏ file JPG vào thư mục này, đặt đúng tên dưới đây. Ảnh tỉ lệ dọc 4:5 là đẹp nhất. App tự dùng ảnh thật thay cho hình vẽ, không cần sửa code.

| Tên file | Góc chụp |
|---|---|
| `pho-topdown.jpg` | Tô phở / bún / mì – Từ trên xuống |
| `pho-angle.jpg` | Tô phở / bún / mì – Nghiêng 45° |
| `pho-close.jpg` | Tô phở / bún / mì – Đũa gắp sợi (cận cảnh) |
| `pho-offset.jpg` | Tô phở / bún / mì – Lệch tâm + chanh/ớt |
| `table-topdown.jpg` | Cả bàn nhiều món – Từ trên xuống |
| `table-angle.jpg` | Cả bàn nhiều món – Nghiêng chéo 45° |
| `table-hands.jpg` | Cả bàn nhiều món – Có tay gắp món |
| `dish-angle.jpg` | Một món cận cảnh – Nghiêng 45° |
| `dish-topdown.jpg` | Một món cận cảnh – Từ trên xuống |
| `dish-low.jpg` | Một món cận cảnh – Ngang tầm đĩa |
| `drink-side.jpg` | Đồ uống – Ngang tầm ly |
| `drink-topdown.jpg` | Đồ uống – Từ trên xuống |
| `drink-hand.jpg` | Đồ uống – Cầm ly trên tay |
| `shop-front.jpg` | Quán / biển hiệu – Chính diện mặt tiền |
| `shop-corner.jpg` | Quán / biển hiệu – Đứng chéo góc |
| `shop-inside.jpg` | Quán / biển hiệu – Không gian bên trong |
| `portrait-face.jpg` | Selfie cùng món – Mặt + món bên cạnh |
| `portrait-chop.jpg` | Selfie cùng món – Gắp món lên |
